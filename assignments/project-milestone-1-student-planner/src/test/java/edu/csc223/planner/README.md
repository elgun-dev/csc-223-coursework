# Test location

Milestone 1 contains only a console entry point. Compilation, exit status, and complete console output are checked in the saved execution evidence; no domain-test suite is claimed at this stage.

After scope approval, introduce JUnit 5 tests here alongside the first domain classes. Cover unique IDs, blank titles, invalid priorities, malformed dates, unchanged state after rejection, queue order, sorting ties, and dependency cycles as those features are implemented. Keep performance experiments separate from correctness tests.
